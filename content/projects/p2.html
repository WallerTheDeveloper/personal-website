Highlights

  • The client never determines game outcomes. The server owns simulation, collision, and territory state. The client handles input, rendering, and prediction
  • Client is built with Unity 3D (URP) and C#, server is built with Rust and Tokio. The server uses a custom binary protocol over TCP for low-latency state sync

Stack

Unity 6, C#, Rust, Tokio, TCP, UDP, Google.Protobuf
